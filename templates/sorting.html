Available Algorithms

1. Bubble Sort

Compares adjacent elements and swaps them if they are in the wrong order.

2. Selection Sort

Finds the smallest element and places it in its correct position.

3. Insertion Sort

Builds a sorted list by inserting each element into its proper position.

4. Merge Sort

Divides the list into smaller parts, sorts them, and merges them together.

5. Quick Sort

Uses a pivot to divide elements into smaller and larger groups, then sorts them recursively.
